# สถานการณ์ทดสอบ RouteAlert (40 สถานการณ์)

- **S01–S20** (20 ข้อ) การใช้งานหลายผู้ใช้พร้อมกัน: แจ้งเหตุ, โรงพยาบาลหลายแห่ง, รับเคส, ปฏิบัติงาน, แจ้งเตือน
- **G01–G20** (20 ข้อ) GPS และตำแหน่ง: ตำแหน่งผู้แจ้ง, คุณภาพสัญญาณ, เรดาร์ผู้ขับขี่, ตำแหน่งรถพยาบาล

เอกสารนี้สร้างจาก `tools/multi_user_sim/src/catalog.mjs` — แก้ที่ไฟล์นั้นแล้วรัน `node src/scenario_report.mjs --doc=../../docs/TEST_SCENARIOS.md`

ทุกสถานการณ์ทดสอบอัตโนมัติ รันทั้งหมดด้วยคำสั่งเดียว: `tools/run_all_scenarios.sh` (ดูหัวข้อท้ายเอกสาร)

ชุดทดสอบที่ใช้:

- **จำลองหลายเครื่อง (Firestore emulator)** — ผู้ใช้จำลองแต่ละคนใช้การเชื่อมต่อ Firebase แยกกันเหมือนมือถือคนละเครื่อง ทำงานพร้อมกันจริงบนฐานข้อมูลจำลอง
- **Dart — โค้ดจริงของแอป** — `flutter test` เรียก service จริงของแอป (IncidentService, ตัวแจ้งเตือน, เรดาร์) กับ Firestore จำลองที่มี transaction แบบเดียวกับของจริง
- **ตัวส่งแจ้งเตือน (Worker)** — ตัวส่ง push จริงกับ Firestore/FCM จำลอง

## บั๊กที่พบจากการคิดสถานการณ์เหล่านี้ (แก้แล้ว)

- **S04 แจ้งเหตุตอนเน็ตหลุด / เซิร์ฟเวอร์ไม่รับ** — เดิมส่งไม่สำเร็จแต่ cooldown 2 นาทีเริ่มนับแล้ว ผู้แจ้งส่งใหม่ไม่ได้
- **S05 ER ของโรงพยาบาลที่ใกล้ที่สุดเต็ม / เกิดเหตุไกลจากโรงพยาบาล** — เดิมรายการเคสซ่อนเคสที่ไกลเกิน 5 กม. ทำให้ไม่มีโรงพยาบาลไหนเห็นเคสนั้นเลย
- **S10 โรงพยาบาล 2 แห่งส่งรถว่างคันเดียวกันไปคนละเคส** — เดิมทั้งสองสำเร็จ รถ 1 คันถือ 2 เคส (transaction ล็อกแค่เอกสารเคส)
- **S17 โรงพยาบาลปิดเคสระหว่างรถกำลังไป** — เดิมการเลื่อนสถานะเขียนทับ ทำให้เคสที่ปิดแล้วกลับมาเปิด
- **S18 ผู้แจ้งกดยกเลิกพร้อมกับที่รถกดรับเคส** — เดิมเช็คจาก cache ในเครื่องแล้วเขียนทับ เคสถูกยกเลิกทั้งที่รถกำลังไป และเน็ตหลุดก็ตอบว่ายกเลิกสำเร็จ
- **G02 ผู้แจ้งไม่ได้อนุญาต GPS / ปิด GPS** — เดิมคืนพิกัดประตูท่าแพเมื่อหา GPS ไม่ได้ เคสถูกปักไว้ที่ท่าแพโดยไม่มีคำเตือน รถพยาบาลจะไปผิดที่
- **G03 GPS ช้า (ในตึก/เพิ่งเปิดเครื่อง)** — เดิมเกิน 3 วินาทีก็ใช้พิกัดท่าแพทันที ไม่ลองตำแหน่งล่าสุดที่รู้
- **G07 GPS ขัดข้องกลางทาง (ปิด GPS / สัญญาณหาย)** — เดิม GPS error → ส่งพิกัดประตูท่าแพเข้าไป รถพยาบาลกระโดดไปท่าแพแล้วประกาศให้ทุกเครื่อง (โรงพยาบาลเลือกรถผิดคัน ผู้ขับขี่แถวท่าแพได้เตือนผิด) และรถที่ไม่มี GPS ประกาศพิกัดตั้งต้นในอำเภอฝาง

## วิธีรัน

```bash
cd route-alert-app
tools/run_all_scenarios.sh             # ทุกชุด (~10–20 นาที) → tools/multi_user_sim/results/scenarios-*.md
tools/run_all_scenarios.sh --quick     # เฉพาะ Dart + Worker (~1 นาที, ไม่ต้องมี Java)
tools/run_all_scenarios.sh --legacy    # ตัวจำลองใช้ตรรกะก่อนแก้ ไว้แสดงว่าจับบั๊กเดิมได้
tools/run_all_scenarios.sh --results   # เก็บผลการทดลอง (ตัวจำลอง 3 รอบ + ก่อนแก้ 1 รอบ) → docs/TEST_RESULTS.md
```

ผลการทดลองจริง (ตัวเลขที่วัดได้ เปรียบเทียบก่อน/หลังแก้ ผลรายกรณี): [TEST_RESULTS.md](TEST_RESULTS.md)

ตัวจำลองต้องมี Node 20+, Java 11+ และไฟล์ Firestore emulator (`firebase emulators:start --only firestore` ครั้งแรกจะดาวน์โหลดให้)

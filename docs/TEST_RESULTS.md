## 6. ข้อจำกัดของการทดลอง

- ฐานข้อมูลเป็น Firestore Emulator ในเครื่องเดียวกัน ไม่มีความหน่วงและการหลุดของเครือข่ายมือถือจริง ตัวเลขเวลาจึงต่ำกว่าการใช้งานจริง และช่วงเวลาเสี่ยงของตรรกะก่อนแก้บนเครือข่ายจริงน่าจะกว้างกว่าที่วัดได้
- ตำแหน่ง GPS เป็นค่าที่ป้อนให้โค้ดจริงของแอป (จำลองสัญญาณดี/อ่อน/กระโดด/ขัดข้อง) ไม่ได้รับจากดาวเทียมจริง
- การเคลื่อนที่ของรถในสถานการณ์ครบวงจรเร่งเวลา 20 เท่า และระยะทางใช้เส้นตรงแทนเส้นทางถนนจริง
- การแสดงผลบนหน้าจอ แจ้งเตือนของระบบปฏิบัติการ และ Dynamic Island ทดสอบด้วยมือถือจริงตามตารางใน tools/multi_user_sim/README.md
